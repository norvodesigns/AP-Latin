# Lectio's mark

The cursive **L** from Lectio's wordmark (Italianno, SIL OFL 1.1; the font is in `ios/Lectio/Resources/Fonts`).

| File | What it is |
| --- | --- |
| `Lectio-L.svg` | The L as one vector path, black, on a 1024 square, centred. Best for Icon Composer: it can fill or tint a vector layer. |
| `Lectio-L-rubric.png` | 2048 square, transparent, rubrication red `#9D2F24` (the light-mode accent). The L's box is centred, 68% of the canvas high. |
| `Lectio-L-coral.png` | Same, `#E0796A` (the dark-mode accent). |
| `Lectio-L-white.png` | Same, white. For a glass layer, or one Icon Composer should tint. |
| `Lectio-L-black.png` | Same, black. For monochrome layers. |
| `Lectio-L-rubric-tight.png` | The L alone, cropped to its ink with a small margin (1443 x 1482), for placing freely. |

The current app icon (`ios/Lectio/Resources/Assets.xcassets/AppIcon.appiconset`) is this L, rubric on parchment
(`#F6F1E6`) with a dark twin (coral on `#17140F`).

Palette for backgrounds and accents: parchment `#F6F1E6`, deep rubric `#6F1E17` to `#9D2F24`, ink `#17140F`,
gilt `#8A6D24` (light) / `#CFA94D` (dark), verdigris `#3F8A6D`, woad `#3F6A94`.
